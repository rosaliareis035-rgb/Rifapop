O botão "Enviar reserva pelo WhatsApp" abre uma conversa com o número configurado e preenche a mensagem com os números escolhidos, total, nome e WhatsApp do comprador.

ATENÇÃO:
A versão atual ainda usa uma lista/localStorage no navegador para o estado dos números. Isso não sincroniza reservas entre celulares. Para uso público com reservas reais, recomenda-se implementar um backend/banco de dados antes de divulgar.
