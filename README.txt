RIFAPOP - SITE + PAINEL ADMINISTRATIVO

Arquivos:
- index.html = site público
- admin.html = painel administrativo
- style.css / script.js = site
- admin.css / admin.js = painel

Como abrir:
1. Abra index.html para o site.
2. Abra admin.html para o painel.
3. Senha inicial do painel: 123456.

IMPORTANTE:
Esta versão é uma demonstração local e salva dados no navegador (localStorage).
Para uso real, é necessário conectar a um banco de dados/backend para sincronizar reservas entre todos os clientes.

Antes de publicar:
- Troque a chave PIX no site/painel.
- Configure o WhatsApp.
- Troque a senha do administrador.
